
📌 Project Overview This project demonstrates the end-to-end development of a modern Data Warehouse and Analytics solution using SQL Server.

The project consolidates data from multiple source systems, including CRM and ERP datasets, into a centralized Data Warehouse. The data is then cleaned, transformed, integrated, and modeled into a Star Schema to support analytical reporting and business insights. 

The project follows the Medallion Architecture, consisting of: 

    🥉 Bronze Layer – Raw data ingestion 
    
    🥈 Silver Layer – Data cleansing and transformation 
    
    🥇 Gold Layer – Business-ready analytical data
